# Voice Samples for XTTS v2 Voice Cloning

Place `.wav` or `.mp3` voice reference files here for XTTS v2 zero-shot voice cloning.

## Requirements
- **Format**: WAV (preferred) or MP3
- **Duration**: 6-30 seconds per clip
- **Quality**: Clean audio, no background noise/music/echo
- **Quantity**: 3-5 clips recommended for best results
- **Content**: Natural speech — different sentences, varied emotional tones

## How to add voice samples
1. **Via the app**: Go to the Onboarding page → Stage 2 → Upload voice files
2. **Manually**: Drop `.wav` files directly into this folder

The server will automatically pick up any `.wav` files in this directory.
